Les crises des cryptomonnaies, du point de vue des acteurs

L'état de crise révèle ce que les acteurs considèrent comme « normal » et ce qui ne l'est pas : est reconnu un hiatus entre les actions prescrites par la conception (et les concepteurs) et les actions réellement effectuées (par les utilisateurs).

« Code is Law » quand « Code is flaw » ?

L'acception rigoriste du slogan « code is law » vide de tout fondement les concepts mêmes de failles, de vulnérabilités, de bogues, voire d'attaques. Du point de vue qui se veut purement descriptif de ce que le code permet effectivement, tout ce qui arrive est « normal ».

Deux grandes familles de crises protocolaires

Les bitcoiners utilisant / forgeant une terminologie de crise mobilisent par là une normativité supposant un « contrat social » et des dispositifs variés, sans lesquels aucun écart problématique entre le code et les attentes ne pourrait être identifié.

…ce qui est ATTENDU = considéré comme légitime par le consensus social
…ce qui est INATTENDU = considéré comme illégitime par le consensus social
