Two major families of protocol crises

…what is EXPECTED — considered legitimate by social consensus
…what is UNEXPECTED — considered illegitimate by social consensus
The code ALLOWS…
The code FORBIDS…
[a] Normal situation Action: Status quo

Ex.: double-spending control, monetary creation following planned schedule, expected settlement.

[b] “Vulnerability” crisis Action: Patch / mitigate

Ex.: exposure, DoS, fake-confirmation — code allows what society rejects.

[c] “Evolution” crisis Action: Protocol change

Ex.: feature gaps — code forbids what society expects (scalability, UX, fees).

[d] Normal situation Action: Status quo

Ex.: rejection of double-spend, invalidation of unauthorized minting, ledger uniqueness.
